SMARTFINDER DATABASE CONNECTION GUIDE
===================================

1. DATABASE CONFIGURATION
------------------------
The database connection is configured in `config.php` with the following parameters:

```php
define('DB_HOST', 'localhost');     // Database host
define('DB_NAME', 'smartfinder');   // Database name
define('DB_USER', 'root');          // Database username
define('DB_PASS', '');              // Database password
define('SITE_URL', 'http://localhost/smartfinder'); // Site URL
```

2. DATABASE CONNECTION CLASS
---------------------------
The main database connection is handled in `Database.php`:

```php
class Database {
    private $host = DB_HOST;
    private $db_name = DB_NAME;
    private $username = DB_USER;
    private $password = DB_PASS;
    public $conn;

    public function getConnection() {
        $this->conn = null;
        try {
            $this->conn = new PDO(
                "mysql:host=" . $this->host . ";dbname=" . $this->db_name,
                $this->username,
                $this->password
            );
            $this->conn->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
        } catch(PDOException $e) {
            echo "Connection Error: " . $e->getMessage();
        }
        return $this->conn;
    }
}
```

3. HOW TO USE THE DATABASE CONNECTION
-----------------------------------
To use the database connection in any PHP file:

```php
require_once 'config.php';
require_once 'Database.php';

$database = new Database();
$db = $database->getConnection();

// Example query
$query = "SELECT * FROM users";
$stmt = $db->prepare($query);
$stmt->execute();
```

5. SECURITY CONSIDERATIONS
-------------------------
1. Always use prepared statements to prevent SQL injection
2. Never store plain text passwords
3. Use proper error handling
4. Implement connection pooling for better performance
5. Regular backup of database

7. ERROR HANDLING
----------------
Always implement proper error handling:

```php
try {
    $database = new Database();
    $db = $database->getConnection();
    
    // Your database operations here
    
} catch(PDOException $e) {
    echo "Error: " . $e->getMessage();
    // Log the error
    error_log("Database Error: " . $e->getMessage());
}
```

9. TROUBLESHOOTING
-----------------
Common issues and solutions:

1. Connection Refused:
   - Check if MySQL server is running
   - Verify host, username, and password
   - Check firewall settings

2. Access Denied:
   - Verify user permissions
   - Check database name
   - Verify user privileges

3. Slow Queries:
   - Check indexes
   - Optimize queries
   - Monitor server resources

4. Connection Timeout:
   - Check server load
   - Verify network connection
   - Adjust timeout settings
